# 🚨 RecoveryBoard + RescueMesh — Frontend

A modern disaster emergency, recovery, and response web platform designed to help citizens and authorities coordinate disaster reporting, recovery activities, and emergency response.

## 🎯 Project Overview

RecoveryBoard + RescueMesh provides a digital platform for managing disaster incidents, citizen reports, recovery workflows, and emergency response coordination.

The frontend is built using lightweight web technologies and is designed to communicate with a FastAPI backend.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* REST API
